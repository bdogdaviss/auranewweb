# Aura Optimizer Competitive Analysis Dashboard

A Go-based web application serving an interactive competitive analysis dashboard for Aura Optimizer vs Hone.gg and Razer Cortex.

## 🚀 Quick Start

```bash
# Clone/navigate to project
cd aura-optimizer-analysis

# Run the Go server
go run main.go

# Open browser
open http://localhost:3000
